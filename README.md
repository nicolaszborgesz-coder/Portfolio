## 🖥️ Sobre o projeto

O objetivo deste portfólio é apresentar meus conhecimentos em desenvolvimento web, programação e automação, além de reunir projetos desenvolvidos durante minha jornada de aprendizado.

A página foi organizada para facilitar a navegação e permitir que recrutadores, empresas e profissionais da área conheçam meus trabalhos.

## 🚀 Projetos em destaque

### 01. MERCON — Conciliação Contábil

Automação desenvolvida em Python para comparar informações de notas fiscais XML com extratos bancários e organizar os resultados em planilhas Excel.

**Tecnologias:**
- Python
- XML
- Excel
- OpenPyXL

Repositório: [MERCON — Conciliação Contábil](https://github.com/nicolaszborgesz-coder/mercon-contabilidade)

### 02. MERCON — Portal Contábil

Sistema web desenvolvido para demonstrar funcionalidades de um portal de escritório contábil, incluindo autenticação, cadastro e gerenciamento de clientes e painel administrativo.

**Tecnologias:**
- Python
- Flask
- SQLite
- HTML
- CSS

Repositório: [MERCON — Portal Contábil](https://github.com/nicolaszborgesz-coder/mercon_portal_contabil)

### 03. Controle de Avanço de Fornos Industriais

Projeto demonstrativo para acompanhamento de avanço físico de atividades industriais, com planejamento, análise de desempenho, relatórios e dashboard.

**Tecnologias:**
- Python
- Excel
- OpenPyXL
- Matplotlib
- HTML
- CSS
- JavaScript

Repositório: [Controle de Avanço de Fornos Industriais](https://github.com/nicolaszborgesz-coder/controle-avanco-fornos-industriais)

### 04. Pixel do Saber | Gestões

Sistema desktop de gestão desenvolvido em Python, com interface gráfica e banco de dados local. Possui módulos para clientes, funcionários, fornecedores, produtos, matérias-primas e pedidos, além de importação e exportação de arquivos CSV.

**Tecnologias:**
- Python
- Tkinter
- SQLite
- CSV
- Hashlib

Repositório: [Pixel do Saber | Gestões](https://github.com/nicolaszborgesz-coder/pixel-do-saber-gestoes)

## ▶️ Como executar localmente

1. Faça o download ou clone o repositório:

```bash
git clone https://github.com/nicolaszborgesz-coder/Portfolio.git
```

2. Entre na pasta:

```bash
cd Portfolio
```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências ou configurar um servidor para visualizar a versão estática do portfólio.

## 🌐 Publicação com GitHub Pages

O projeto utiliza GitHub Pages para hospedagem.

Para publicar ou atualizar:

1. Acesse o repositório Portfolio no GitHub.
2. Envie os arquivos atualizados.
3. Verifique se o arquivo `index.html` está na raiz.
4. Acesse **Settings → Pages**.
5. Configure a publicação pela branch principal (`main`), utilizando a pasta `/ (root)`.
6. Aguarde a atualização do site.
